## 🙋‍♂️ About Me

I am a Software Engineer specializing in building scalable, resilient, and high-performance backend systems. My core engineering philosophy revolves around writing enterprise-grade clean code, designing decoupled distributed architectures, and optimizing algorithmic workflows.

### 🚀 What I'm Building

* 🎪 **[Event-Management-System](https://github.com/Shubhamkale1/Event-Manager)** — A production-ready, cloud-ready event platform. Built using a **Spring Boot** backend, **Kafka** distributed messaging for asynchronous event notification pipelines, **Elasticsearch** for typo-tolerant fuzzy search indexing, and **Redis** abstraction layers for extreme read caching optimization under high concurrent load.
  
* 💳 **[BankingPortal API](https://github.com/Shubhamkale1/BankingPortal-API)** — A secure, high-integrity enterprise banking backend utilizing **Spring Boot**, stateless **JWT** token architecture with Redis-backed distributed blacklisting, and **Spring Actuator** endpoints integrated for infrastructure visibility.
